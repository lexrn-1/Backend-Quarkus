LIMITACIONES Y PENDIENTES EXTERNOS
- Docker CLI existe, pero el usuario de ejecución no accede a /var/run/docker.sock.
  docker info: permission denied. sudo no interactivo requiere contraseña.
  No se construyeron imágenes ni se arrancó Compose en esta entrega.
- No se publicaron GitHub/GHCR/Dokploy/Vercel ni se aplicaron índices/reglas a Firebase real.
- No se validaron firmas con Firebase real en estas pruebas; los tokens son de Auth emulado.
- No se acreditan HTTPS/WSS público, reconexión por Traefik, ni TURN entre redes/dispositivos.
- TURN_USERNAME/TURN_PASSWORD vacíos o xxxxxxxx deshabilitan TURN; faltan valores reales.
- El emulador no verifica índices productivos. Aplicar los índices versionados al publicar.
- Capacidad/presencia en memoria: una réplica realtime; esto no certifica latencia bajo carga real.
- Dominios institucionales siguen pendientes por decisión del usuario.
- Catálogo, horarios, adjuntos, tablero, no leídos y edición/borrado de perfiles fuera de alcance.
